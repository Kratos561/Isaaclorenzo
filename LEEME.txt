1. CÓMO VER LA WEB (IMPORTANTE)
----------------------------------------------------------------
NO abrir con doble clic (protocolo file://). Los videos de YouTube
incrustados fallan con "Error 153" sin un origen http/https válido.

Usar siempre el servidor local incluido:
  1. Ejecutar:  Portafolio\servidor-local.ps1
     (PowerShell: powershell -ExecutionPolicy Bypass -File .\servidor-local.ps1)
  2. Abrir:     http://localhost:8000/index.html

El servidor sirve la carpeta en el puerto 8000 con MIME correcto
(html, css, js, svg, jpg, png, json). Al publicar en un hosting
https (Netlify, Vercel, GitHub Pages) todo funciona sin el script.

7. ANIMACIONES GSAP (skills: gsap-core, gsap-timeline, gsap-scrolltrigger)
----------------------------------------------------------------
CDNs (cdnjs 3.12.5, antes del script inline, en las 3 páginas):
  gsap.min.js + ScrollTrigger.min.js + assets/animations.js
assets/animations.js contiene (todo dentro de gsap.matchMedia):
  - Timeline de entrada del hero con labels (solo páginas con .hero__grid,
    o sea 3d/videos; la portada ya no tiene rejilla).
  - PORTAFOLIO: respiración (scale 1→1.015) + brillo suave viajando por
    letras (opacity, stagger yoyo infinito) + inclinación 3D con cursor
    (quickTo rotationX/Y, solo puntero fino) + parallax scrub.
  - Logo flotante (yoyo) en heroes de subpáginas (.hero__logo img).
  - Parallax scrub en .hero__name (con guards si no existe).
  - Reveals [data-reveal] por lotes (ScrollTrigger.batch, start "top 88%",
    once:true, stagger 0.12) según data-from (up/right/mask con clip-path).
  - Marquee infinito (duplica hijos con aria-hidden, loop x lineal 24s).
  - Botones .btn magnéticos (quickTo, solo puntero fino).
  - Retrato .portrait con deriva scrub.
  - ScrollTrigger.refresh() en window load.
Reglas de las skills aplicadas: registerPlugin, defaults, camelCase y
aliases de transform (x/y/scale/rotation/autoAlpha), eases documentados,
matchMedia con prefers-reduced-motion (sin animación si se pide),
sin scrub+toggleActions juntos, sin ScrollTrigger en tweens anidados.
FALLBACK: si el CDN falla, los scripts inline (reveal por
IntersectionObserver) y el CSS mantienen la web usable. Los reveals
inline se desactivan solos si window.gsap+ScrollTrigger existen.
